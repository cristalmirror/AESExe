AESExe - v0.4.1

Este sistema permite a sus usuarios tener un sistema de gestion de contraseñas seguras. Permite utilizar contraseñas de guardandolas de forma cifrada que hacen solo el usuario con un archivo key. este archivo key se descargara automaticamente permitiendo desifrar luego las contraseñas. de esa manera pueden verlas.

Desarrollado por cristalmirror: https://github.com/cristalmirror/AESExe
